# Смена — работа, услуги и аренда персонала

Веб-приложение на **Python 3.12 / Django 5.2 / PostgreSQL**. Русский интерфейс, адаптивные HTML-шаблоны, CSS и небольшой JavaScript для предварительного расчёта аренды. SQLite доступна для локального знакомства и тестов.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
docker compose up -d db
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

Приложение: http://127.0.0.1:8000/. Админка: http://127.0.0.1:8000/admin/.

При использовании существующего PostgreSQL укажите параметры подключения в `.env`; Docker необязателен. `.env` загружается автоматически, переменные окружения имеют приоритет. Если порт 5432 занят, измените проброс в `compose.yaml` и `POSTGRES_PORT` в `.env`.

### Локально без PostgreSQL

После установки зависимостей:

```bash
DB_ENGINE=sqlite python manage.py migrate
DB_ENGINE=sqlite python manage.py seed_demo
DB_ENGINE=sqlite python manage.py runserver
```

Либо укажите `DB_ENGINE=sqlite` в `.env`.

### Обновление существующего проекта

Сохраните резервную копию своей базы и каталога `media/`, затем выполните:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py check
```

Перезапустите сервер приложения. Для демонстрации новых сценариев можно повторно выполнить `python manage.py seed_demo`: существующие пароли и статусы не сбрасываются. Команда дополняет незаполненные новые поля демонстрационных профилей, создаёт недостающие примеры.

Миграции сохраняют существующие профили и публикации. Для старых заказов и заявок заполняется стоимость по текущей цене связанной услуги или предложения на момент обновления: прежняя версия приложения исторические цены не хранила. Все новые заявки фиксируют цену при отправке.

## Что умеет приложение

### Работодатель

- Профиль компании: сфера, город, описание, контакты и сайт; публичная страница с открытыми вакансиями.
- Создание, изменение и удаление вакансий, архив и восстановление публикаций.
- Входящие отклики, фильтр по статусу, просмотр резюме и портфолио кандидатов.
- Статусы «На рассмотрении», «Приглашение», «Отказ», «Принят на работу».
- Поиск по базе резюме, прямые приглашения на собеседование и ответы кандидатов.
- Заказ услуг на выбранную дату, отмена нового или подтверждённого заказа.
- Один отзыв с оценкой 1–5 после выполненного заказа.
- Предложения персонала: специальность, категория, город, количество, период и дневная ставка.
- Поиск команд других компаний, заявки на аренду, подтверждение и отклонение входящих заявок, отмена своих заявок до начала аренды включительно.
- CSV-выгрузка собственных откликов с защитой от формул в пользовательском тексте.

### Соискатель и исполнитель

- Регистрация и вход по email без учёта регистра, изменение имени и пароля, восстановление пароля.
- Резюме: специализация, город, желаемая зарплата, навыки, опыт, контакты; переключатель видимости в поиске и предварительный просмотр.
- Портфолио: отдельные проекты с описанием, внешней ссылкой и загружаемым материалом.
- Поиск вакансий по тексту, городу, категории, типу занятости и зарплате.
- Отклик, отслеживание статуса, отзыв своего отклика и повторная отправка отозванного отклика на открытую вакансию.
- Ответ на прямое приглашение: принять или отклонить.
- Свои услуги, входящие заказы, подтверждение или отказ, этапы «Подтверждён → В работе → Выполнен».
- Месячный календарь, ручные отметки готовности и занятости, отображение заказов и экспорт `.ics` на ближайший год.
- Отзывы, средний рейтинг и сумма выполненных заказов в личном кабинете. Сумма отражает стоимость выполненных заказов, а не поступление оплаты.

### Общие возможности

- Переписка между участниками: начало диалога из вакансии, услуги, резюме, предложения персонала, заказа или заявки на аренду; история, поиск диалогов, непрочитанные сообщения и отметки прочтения.
- Один диалог на пару участников, даже если они познакомились через разные публикации.
- Центр уведомлений о новых откликах, заказах, приглашениях, отзывах, сообщениях и изменениях статусов; счётчик и отметка прочтения.
- Избранное для вакансий, услуг, предложений персонала и резюме.
- Расширенные фильтры: категории, города, диапазон цен, период и размер команды; сортировка по оплате и рейтингу услуг.
- Обновлённая главная страница: поиск, категории, свежие вакансии и услуги.
- Личный кабинет со сводными показателями, навигацией по задачам и независимой пагинацией разделов.
- Настройки аккаунта и оформленные страницы смены/восстановления пароля.
- Админка с поиском, фильтрами, массовым архивированием и просмотром новых сущностей.

## Правила рабочих сценариев

### Заказы услуг

Стоимость копируется в `Order.agreed_price` при отправке заказа. Изменение цены услуги не меняет стоимость существующего заказа. Новые заказы нельзя отправлять на прошедшую или уже занятую дату. При подтверждении занятость проверяется повторно.

Один исполнитель не может одновременно подтвердить два заказа на одну дату, включая заказы на разные его услуги. Проверка использует транзакцию и блокировку строки исполнителя в PostgreSQL. Отметка «занят» в календаре запрещает подтверждение; существующий подтверждённый заказ нельзя перекрыть такой отметкой. После отмены заказ освобождает дату. Ожидающие подтверждения заявки сами по себе дату не резервируют.

Заказчик отменяет заказ в статусах «Ожидает подтверждения» и «Подтверждён». Исполнитель отклоняет новый заказ или последовательно проводит его через рабочие этапы. Выполненные и отменённые заказы нельзя переоткрыть. Отзыв доступен только заказчику выполненного заказа.

### Аренда персонала

Период должен находиться внутри предложения, количество — быть положительным и не превышать размер команды. Согласованная ставка сохраняется в `Rental.agreed_rate`. Стоимость: **ставка × количество × число дней**, обе граничные даты включаются.

При подтверждении блокируется предложение и рассчитывается максимальная одновременная занятость по дням, а не сумма всех пересекающихся заявок. Поэтому две непересекающиеся аренды не занимают персонал одновременно. Подтверждённые заявки нельзя переоткрывать; отмена заказчиком до начала включительно освобождает персонал. Количество и срок предложения с подтверждёнными заявками менять нельзя. Архив скрывает предложение из поиска и запрещает новые заявки, сохраняя текущие договорённости.

### Архив, история и приватность

Архивированные публикации не показываются в каталогах. Доступ к их деталям сохраняется у автора и участников связанных откликов, заказов или аренд. Новые отклики, заказы и заявки на аренду по архивированной публикации запрещены. Удаление публикации со связанными заявками блокируется; используйте архив.

Скрытое резюме исключается из поиска и перестаёт открываться через избранное у новых работодателей. Доступ сохраняется у работодателей, с которыми уже был отклик или прямое приглашение. Автор может просмотреть собственное резюме. Диалоги, уведомления, избранное и выгрузки проверяют принадлежность пользователю на сервере.

### Материалы портфолио

Поддерживаются PDF, PNG, JPEG и WebP до 10 МБ; проверяются расширение и начальная сигнатура. Материалы сохраняются в `media/portfolio/<user_id>/` со случайными именами и отдаются как скачиваемые вложения через `/portfolio/<id>/download/`. Это проверка формата, а не антивирусный анализ.

Материал скачивает автор или работодатель, которому доступно резюме, активная услуга автора либо собственный предыдущий заказ. Сотрудник админки с правом просмотра проектов также может скачать материал. Анонимам и другим соискателям доступ закрыт. Не настраивайте публичную раздачу `media/`: доступ должен идти через защищённый endpoint. При замене или удалении проекта старые файлы автоматически не удаляются; учитывайте это при обслуживании хранилища.

## Восстановление пароля и почта

В режиме разработки используется консольный email-backend: ссылка восстановления появляется в терминале Django. Для реальной отправки настройте SMTP через `.env`:

```dotenv
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_HOST_USER=your-account
EMAIL_HOST_PASSWORD=your-password
EMAIL_USE_TLS=1
DEFAULT_FROM_EMAIL=Смена <noreply@your-domain.example>
```

Ссылка действует один час, после использования становится недействительной. Страница не сообщает, существует ли введённый email. Уведомления о рабочих событиях находятся внутри приложения; они не рассылаются по email. Переписка обновляется при загрузке страницы, WebSocket не используется.

## Проверки

```bash
DB_ENGINE=sqlite python manage.py check
DB_ENGINE=sqlite python manage.py test
DB_ENGINE=sqlite python manage.py makemigrations --check --dry-run
```

Тесты проверяют регистрацию, вход, права ролей и владельцев, каталоги и фильтры, архив и сохранение истории, отклики, приглашения, жизненный цикл заказа, бронирование даты, стоимость и лимиты аренды, отзывы, приватность резюме, переписку, уведомления, избранное, портфолио, загрузку файлов, CSV/ICS, смену и восстановление пароля, пагинацию, админку, CSRF и повторяемость демоданных.

Для проверки на PostgreSQL выполните те же команды без `DB_ENGINE=sqlite`; пользователь БД должен иметь право создавать тестовую базу. SQLite не обеспечивает блокировки `SELECT FOR UPDATE`, поэтому проверка конкурентных запросов требует PostgreSQL.

В этой среде проверки выполнялись на Django **5.2.18** и SQLite. Доступ к Docker daemon и запуск локального HTTP-сервера запрещены окружением; проверка PostgreSQL и визуальная проверка в браузере здесь не выполнены.

## Развёртывание

Укажите уникальный `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, конкретные домены в `DJANGO_ALLOWED_HOSTS`, параметры PostgreSQL и SMTP. Выполните миграции и `python manage.py collectstatic`, настройте HTTPS, reverse proxy и раздачу `/static/` из `staticfiles/`. Сохраняйте `media/` как приватное постоянное хранилище вместе с резервными копиями БД.

```bash
gunicorn config.wsgi:application --bind 127.0.0.1:8000
```

При `DEBUG=0` включаются Secure-cookie сессии и CSRF. Выполните `python manage.py check --deploy` и настройте параметры HTTPS-прокси под инфраструктуру. Шрифт загружается из Google Fonts; без внешней сети используется Arial.

Платформа не принимает оплату и не формирует трудовые договоры. Цены и суммы используются для согласования условий и учёта внутри приложения.
